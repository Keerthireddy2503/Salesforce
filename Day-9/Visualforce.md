## Visualforce Visualforce Introduction

### Legacy Salesforce UI Framework

Visualforce is an older Salesforce framework used to build custom user interfaces and pages.

It was introduced before:

* Aura Components
* Lightning Web Components (LWC)

Visualforce pages are created using:

* HTML-like tags
* Apex controllers
* Salesforce components

It helped developers create customized Salesforce applications beyond standard page layouts.

### Historical Understanding

Visualforce is important for understanding the evolution of Salesforce development.

Development progression:

1. Visualforce → Server-side UI framework
2. Aura Components → Component-based framework
3. LWC → Modern web standards-based framework

Many older enterprise Salesforce applications still use Visualforce, so developers may encounter it in maintenance and migration projects.

### Features of Visualforce

* Custom page creation
* Apex integration
* Server-side rendering
* Form handling and data display
* PDF generation support

### Why It Still Matters

* Legacy systems still use it
* Useful for understanding Salesforce history
* Some projects require Visualforce maintenance
* Helps in migration to Aura or LWC

### Limitations Compared to LWC

* Slower performance
* Older architecture
* Less modern UI experience
* More server dependency
