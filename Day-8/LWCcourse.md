## Lightning Web Components Lightning Web Components Crash Course

### HTML + JS + Meta XML

A Lightning Web Component (LWC) is built using three main files:

* **HTML File** → Defines the user interface and page structure
* **JavaScript File** → Handles component logic, events, and data
* **Meta XML File** → Controls component configuration and where it can be used in Salesforce

These files work together to create reusable and interactive Salesforce UI components.

### Component Life Cycle

LWC components follow a life cycle from creation to removal.

Main stages:

* Component creation
* Rendering on the page
* Updating when data changes
* Removal from the page

Lifecycle methods help developers control component behavior during these stages.

### Uses of LWC

* Custom Salesforce applications
* Interactive dashboards
* Forms and data display
* Lightning Experience customization

### Benefits

* Fast performance
* Modern UI development
* Reusable components
* Easy maintenance
* Better user experience
