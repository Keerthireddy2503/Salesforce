## Salesforce Flow Crash Course


### Salesforce Flow Overview

Salesforce Flow is a no-code/low-code automation tool in Salesforce used to automate business processes visually without writing Apex code. It helps automate tasks like creating records, sending emails, updating fields, and guiding users through screens. ([Apex Hours][1])

Common flow types:

* Screen Flow
* Record-Triggered Flow
* Scheduled Flow
* Autolaunched Flow

---

## Automation Concepts

Salesforce Flow works using logic and automation elements connected together in a visual builder.

Basic automation process:
Start → Decision → Action → End

Common automation tasks:

* Auto-update records
* Send notifications
* Create related records
* Automate approvals
* Trigger actions when records change

Flows can run automatically when records are created, updated, or deleted. ([Apex Hours][1])

---

## Beginner-Friendly Flow Understanding

Flow Builder uses simple drag-and-drop elements, making it easier for beginners to learn automation.

Important concepts:

* **Elements** → Actions inside flow
* **Resources** → Store data like variables
* **Decision** → Applies conditions
* **Loops** → Repeat actions
* **Connectors** → Link flow steps

Many Salesforce learners describe Flow as “visual programming” because it uses programming logic in a graphical way. ([Reddit][2])

| Component | Purpose           |
| --------- | ----------------- |
| Start     | Begins the flow   |
| Decision  | Checks conditions |
| Action    | Performs tasks    |
