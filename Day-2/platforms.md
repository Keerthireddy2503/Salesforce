# Salesforce Basics

## 1. App

An **App** in Salesforce is a collection of related tools and features used for a specific purpose.

### Example

A **College Management App** may contain:

* Students
* Faculty
* Courses
* Attendance
* Reports

Just like WhatsApp combines chats, calls, and status in one place, a Salesforce App combines related business features together.

---

## 2. Object

An **Object** is used to store data in Salesforce.
It works like a database table or an Excel sheet.

### Example

A **Student Object** stores student details such as:

* Name
* Roll Number
* Branch
* Year

Sample Record:

* Keerthi – CSE – 3rd Year
* Ravi – ECE – 2nd Year

Here:

* Student = Object
* Name, Branch, Year = Fields
* Each student entry = Record

### Types of Objects

* **Standard Objects**: Already available in Salesforce (Account, Contact, Opportunity)
* **Custom Objects**: Created by users (Student, Attendance, Library)

---

## 3. UI (User Interface)

The **UI** is the screen through which users interact with Salesforce.

It includes:

* Navigation Bar
* Tabs
* Home Page
* Record Pages
* Reports
* Dashboards
* Search Bar

### Example

In a College Management System:

* Users open the College Management App
* Click the Student tab
* View student records
* Search for a student
* Generate attendance reports

---

## Simple Connection Example

* **App** → College Management App
* **Object** → Student
* **Record** → Keerthi – CSE – 3rd Year
* **Field** → Name, Branch, Year
* **UI** → Screens showing student details

---

## Conclusion

* **App** organizes related features together.
* **Object** stores data.
* **UI** helps users interact with Salesforce easily.
