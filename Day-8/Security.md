## Salesforce Salesforce Security Basics

### Profiles and Permissions

Salesforce security controls what users can access and perform in the system.

* **Profiles** define basic user permissions
* **Permissions** control access to objects, fields, apps, and features
* Users receive permissions based on their job roles and responsibilities

Examples:

* Read, create, edit, and delete access
* App and tab visibility
* Apex and system permissions

### Enterprise Security Basics

Salesforce provides security features to protect business data and applications.

Important security areas:

* User authentication
* Role-based access
* Data protection
* Record-level security
* Field-level security

These controls help organizations maintain secure and reliable systems.

### Access Control

Access control determines who can view or modify data.

Main access control methods:

* Organization-wide defaults (OWD)
* Roles and role hierarchy
* Sharing rules
* Profiles and permission sets

This ensures users only access data required for their work.

### Benefits

* Protects sensitive business information
* Improves data security
* Supports compliance requirements
* Reduces unauthorized access
* Enhances enterprise reliability
